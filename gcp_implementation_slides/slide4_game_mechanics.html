Game Mechanics & UI

The DroneAI solution incorporates D&D-style game mechanics to incentivize drone operator skill development through gamification. This slide details the game mechanics architecture, UI implementation, and how GCP services enable this unique approach.

D&D-Style Game Mechanics Framework

Skill Checks

Drone operations are evaluated as D&D-style skill checks with difficulty classes (DC) determined by environmental factors and mission complexity.

Formula:

Success = (Operator Skill + d20 Roll) ≥ Mission DC

Implemented using:

  • Video Intelligence API to assess shot quality
  • Telemetry analysis for flight precision
  • Environmental sensor data for difficulty modifiers
Character Progression

Operators develop character sheets with specialized skills and classes based on their drone operation style.

XP Calculation:

XP Earned = Base Mission XP × Quality Multiplier × Difficulty Modifier

Classes include:

  • Ranger: Specializes in tracking shots and wilderness filming
  • Artificer: Excels at technical shots and drone modifications
  • Bard: Masters cinematic storytelling and artistic compositions
  • Cleric: Focused on safety, reliability, and recovery operations
Missions & Quests

Structured challenges with objectives, rewards, and narrative elements create a campaign-like progression.

Mission types:

  • Main Quests: Major client projects with multiple objectives
  • Side Quests: Skill development challenges and technique practice
  • Daily Challenges: Quick missions focusing on specific skills
  • Guild Raids: Team-based collaborative missions

Missions are stored as templates in Firestore with dynamic difficulty scaling based on operator level.

Loot & Rewards

Successful missions award virtual items and perks that translate to real-world benefits.

Reward types:

  • Equipment: Access to premium drone hardware for future missions
  • Spells: Special post-processing effects and filters
  • Perks: Priority booking for premium locations
  • Currency: "DroneGold" convertible to discounts or real equipment

Cloud Spanner tracks inventory and rewards with ACID transaction guarantees.

GCP Services Enabling Game Mechanics

Serverless Backend Architecture

The game mechanics are powered by a serverless architecture leveraging multiple GCP services:

  • Cloud Functions: Event-driven functions that calculate skill checks, award XP, and process mission results
  • Cloud Run: Containerized services for more complex game logic and mission generation
  • Firestore: NoSQL database storing character sheets, mission templates, and game state
  • Pub/Sub: Event bus for real-time game events and notifications
  • BigQuery: Analytics for game balance, operator statistics, and difficulty scaling

AI-Powered Game Balancing

The system uses AI to continuously balance game mechanics for an optimal experience:

  • AutoML Tables: Predicts appropriate difficulty classes based on operator skill and mission parameters
  • Vertex AI: Custom models for evaluating drone flight technique quality
  • Recommendations AI: Suggests appropriate missions based on operator skill profile

Real-time Multiplayer Support

For collaborative missions, the platform supports real-time interaction between operators:

  • Firebase Realtime Database: Synchronizes mission state across devices
  • Cloud Game Servers: Manages sessions for team-based missions
  • WebRTC: Enables voice communication during collaborative flights

Implementation Roadmap

  1. Phase 1: Core game mechanics implementation (skill checks, character progression)
  2. Phase 2: Mission system with dynamic difficulty scaling
  3. Phase 3: Rewards and inventory system integration
  4. Phase 4: Multiplayer missions and team-based challenges
  5. Phase 5: AI-powered balancing and personalized mission generation
